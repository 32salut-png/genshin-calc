# 原神 ガチャ確率・原石計算ツール

**URL**: https://32salut-png.github.io/genshin-calc/

原神のガチャ確率・必要原石数をシミュレーションするWebツールです。  
インストール不要、ブラウザで即使用可能です。

---

## 機能

### 📊 モンテカルロシミュレーション
- 10万回試行による詳細な確率分布を算出
- 目標凸数（C0〜C6）・武器精錬（R1〜R5）の到達確率を表示
- キャラ/武器への最適な連数配分を自動探索
- 仮天井・確定保証・神鋳軌定（命定値）に対応

### 🔢 必要原石 逆算
- 目標凸数・精錬数から必要な連数・原石数を期待値で逆算
- 現在の手持ちリソースと比較して過不足を即時表示

### 🎲 排出シミュレーター
- 指定連数での★4・★5排出数をシミュレーション
- 仮天井の確率上昇を考慮した正確な期待値を算出

### 📅 バージョン配布原石の自動計算
- シミュレーション期間を設定すると、アップデート・イベント・腕試しなどの配布原石を自動加算
- 過去バージョン1.0から現在まで全バージョンのパッチ日に対応

---

## 技術的な工夫

- **WebWorker化**：10万回のモンテカルロシミュレーションをメインスレッドから切り離し、計算中もUIが固まらない設計
- **最適配分探索**：キャラバナー/武器バナーへの連数配分を粗探索→精密探索の2段階で自動最適化
- **動的パッチスケジュール**：ゲームの全バージョン（1.0〜現在）のパッチ日をテーブルで管理し、期間内の配布原石を正確に算出
- **localStorage永続化**：手持ちリソースをブラウザに保存し、次回アクセス時に自動復元

## 免責事項

- イベント報酬・バージョン配布原石は推定値です
- ガチャ確率は公開情報をもとに実装していますが、ゲーム内の実装との完全な一致を保証するものではありません
- 本ツールはファンメイドであり、HoYoverse（miHoYo）とは無関係です
